# Security

Please do not open a public GitHub issue for a vulnerability that could expose user data, search subjects, API credentials, authentication tokens, private infrastructure, or production systems.

## Report privately

Use the security reporting instructions at:

https://dotheypass.com/security.html

When possible, include:

- affected component
- reproduction steps
- expected vs actual behavior
- security/privacy impact
- screenshots or logs with secrets and unnecessary personal information removed

## Please avoid

- publishing API keys, bearer tokens, or private endpoints
- posting real search subjects or private lookup data in public issues
- destructive testing against production
- accessing data that is not necessary to demonstrate the issue
- retaining or redistributing personal data encountered during testing

## Scope

Security work is especially welcome around:

- authentication and token handling
- rate limiting and abuse resistance
- input validation
- privacy leakage
- sensitive-data redaction
- cross-origin behavior
- cache/indexing controls on private pages
- provider credential isolation
- false-match amplification and integrity risks

Thank you for helping keep the project and the people it may describe safer.
